# ASP.NET Core MVC Data Management System

A data management web application built using **C#, ASP.NET Core MVC, Entity Framework Core, and SQL Server**.

## Features
- CRUD Operations (Create, Read, Update, Delete)
- Sorting and Filtering
- PDF Report Generation
- Excel and CSV Export
- Import Excel Data into SQL Server Database
- Layered Architecture using Services and Interfaces
- Unit Testing with xUnit

## Technologies
- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- xUnit

## Getting Started
1. Clone the repository.
2. Open `MVC_Project.sln` in Visual Studio.
3. Configure the SQL Server connection string.
4. Restore NuGet packages and run the application.
